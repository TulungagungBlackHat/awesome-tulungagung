# 5 Kesalahan Password yang Sering Dilakukan

Cek passwordmu pakai `TBH-PassStrength`:

```bash
python3 checker.py -p "password123"
```

## Kesalahan Umum
1. Pakai `123456` / `password` → skor 0/7
2. Terlalu pendek (<12 char)
3. Tidak ada simbol
4. Pakai tanggal lahir
5. Pakai password sama di semua situs

## Solusi
Gunakan passphrase: `KopiPagi#Tulungagung2026!` → skor 7/7 + aktifkan 2FA

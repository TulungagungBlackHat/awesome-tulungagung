## Tools TBH

Toolset open-source dari Tulungagung Black Hat — Termux-friendly, MIT licensed:

| Tool | Fungsi |
|------|--------|
| [TBH-Toolkit](https://github.com/TulungagungBlackHat/TBH-Toolkit) | Satu repo, 19 subcommand: `tbh recon`, `tbh xss`, `tbh scan`, menu + curses UI |
| [TBH-CTF](https://github.com/TulungagungBlackHat/TBH-CTF) | Mini CTF 3 challenge pemula |

Tool TBH lain (Recon, XSS, PortScanner, ...) sekarang archived, kodenya pindah
ke [TBH-Toolkit](https://github.com/TulungagungBlackHat/TBH-Toolkit) — tinggal
`git clone` sekali, jalanin `python3 tbh`.

## Belajar Gratis

**Web security fundamentals**
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — lab gratis, standar industri
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — 10 risiko web paling penting
- [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) — target latihan legal

**Platform latihan**
- [TryHackMe](https://tryhackme.com) — path terstruktur untuk pemula
- [Hack The Box](https://hackthebox.com) — tantangan lebih menantang
- [OverTheWire](https://overthewire.org) — wargame klasik (Bandit untuk pemula Linux)

**Bug bounty**
- [HackerOne Hacker101](https://www.hacker101.com/) — kursus gratis dari platform bounty
- [Bugcrowd University](https://www.bugcrowd.com/hackers/bugcrowd-university/) — materi triage & reporting
